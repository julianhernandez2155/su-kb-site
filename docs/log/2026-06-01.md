**Discoveries / gotchas**:
- **Robustness gap**: the metadata-first *version-unchanged* short-circuit runs before the *ancestor-based draft* exclusion, so a page newly nested under a `(Test)`/excluded parent won't be re-excluded until its version changes (why the `the-workflow` orphan lingered). The *access* gate is deliberately ordered before the short-circuit, so it's unaffected. Lower-stakes (quality, not security). Candidate fix: surface the access gate's already-fetched ancestors to the draft check.
- Inherited-restriction detection confirmed end-to-end on real data — the 3 intern pages were clean *directly* but restricted via their parent folder.
- `/restriction/byOperation` `limit:200` pagination still unverified above ITSAI's size (already noted in ADR-0003).

**Decisions**: none new — executed [ADR-0003](decisions/0003-public-only-access-classification.md), already accepted.

# 2026-06-08 — Faculty page authoring: gate + drafter shipped, validated live

**Context**: Executed RPI Step 4 (implement) for `faculty-page-authoring` across Phases 1–3, then
committed the whole feature. Goal: a non-technical author drafts a publish-safe KB page in Claude
and it reaches the live site only through a fail-closed gate.

**Done**:
- **Phase 1 — the gate (committed `f737f74`).** `tools/check_frontmatter.py` — native-aware
  validator (explicit `origin: native|confluence` discriminator with `page_id` inference fallback,
  `visibility: public` enforced, native slug/filename match, dept allow-list from `kb_config`).
  17 unit tests incl. the `slugify` drift guard; `validate-content.yaml` PR CI (validates the diff,
  fails closed, independent of `deploy.yaml`); `pull_request_template.md`; `CODEOWNERS`. 17 tests +
  29/29 corpus dry-run green.
- **Phase 2 — the drafter (committed `28b7902`).** `skill/drafter/SKILL.md` (Agent Skill) +
  `drafter-prompt.md` (copy-paste fallback), instruction bodies kept **byte-identical**. Encodes
  the schema rules (mirroring the validator), the `ux.md` conversation design + all 8 interaction
  states, and — added on request — a **house-style guide** drawn from reading 5 live corpus pages
  (page shape, callouts, lists, tables, four page-type skeletons).
- **Renderer finding.** Extracting house style surfaced that `render.py` collapses callout kinds to
  `warning`/`note` and does **not** collapse the `> [!note]-` form (the `-` leaks into the title),
  so some exported mentorAI pages render degraded. Drafter told to avoid it; logged as a candidate
  fast-follow fix (not changed — out of Phase 2 scope).
- **Phase 3 — handoff guide (committed `13a6fe3`).** `docs/authoring/submit-on-github.md` — a
  terminal-free "2 steps" GitHub guide, accessible by construction (each step stands alone without
  the screenshots; placeholders carry action-conveying alt text), linked from the drafter.
- **Live test on SU Claude Enterprise.** Installed the skill (**answers Phase 0.1: skill install IS
  available on SU's tier**) and ran it on a real, private source (a Hermes integration plan). The
  skill stripped all personal context, **independently verified the facts** before writing, fired
  the **sensitive-source safety behavior**, and emitted a native page that **passes the validator
  (exit 0)** and is now live on GitHub Pages. House style + the corrected callout rule followed; the
  flagged cross-link resolves (HTTP 200). Real, unsupervised proof the drafter and gate agree.
- **Self-approval finding → ADR-0004.** The live merge exposed that GitHub forbids a PR author from
  approving their own PR — which, under CODEOWNERS-required review with a sole author-steward, would
  lock that steward out of merging their own content. Pivoted the human gate to **restricted merge
  access** (require PR + required `validate` check + maintainer-only merge); CODEOWNERS demoted to
  advisory. `branch-protection.md` runbook updated.
- **Committed the feature in 5 commits**: gate (`f737f74`), ADR-0004 (`238757e`), drafter
  (`28b7902`), guide (`13a6fe3`), RPI plan+implement docs (`5f353f9`).

**Decisions**: [ADR-0004](../decisions/0004-human-gate-via-restricted-merge-access.md) — human
publish-gate via restricted merge access, not CODEOWNERS-required review.
